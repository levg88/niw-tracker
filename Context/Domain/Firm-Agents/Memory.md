## Facts
<!-- Stable, verified knowledge. One bullet per fact. Tagged. -->
- Agent identity, system prompt, task template, and sampling parameters live in `agents/*.md`; the TypeScript runtime under `src/agents/` is a single script base with no per-role wrappers. (General)
- The loader `src/agents/definitions.ts` searches bundled `agents/` first, then `NIW_AGENTS_DIR` or `<dataDir>/agents` (default `data/agents`); later files override by `id`. (General)
- Definitions use YAML frontmatter plus `# System Prompt` / `# Task` sections; `# Task` supports `{{placeholder}}` variables with JSON pretty-printing for objects. (General)
- The frontmatter `schema:` field maps to a validator in `src/agents/schema.ts`; valid values are `readiness_review`, `report_summary`, and `none`. (General)
- `runAgentById(id, variables, completer)` in `src/agents/dynamic.ts` runs any definition dynamically with an injected completer and validates JSON output; adding a role is one new `.md` file. (General)
